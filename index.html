🎧 foobar2000-plinth - A Quiet Theme Built Around Your Album Art

Plinth is a soft-grey foobar2000 theme that keeps the music in front and everything else out of the way. Album art takes the centre of the window, and the Library, Playlist, Lyrics and About panels slide out only when you ask for them.

Free · Windows · Built on Columns UI and JSplitter

🎨 What Plinth Actually Is

Plinth is a look for foobar2000, not a separate music player. You keep using the foobar2000 you already have, and Plinth changes how it appears on screen. The idea is simple: your album artwork should be the star of the window, and the controls should fade into the background until you need them.

The colour palette is deliberately restrained. Soft greys, gentle contrast, no bright blocks of colour competing with your cover art. Text is calm and readable. Nothing blinks, nothing shouts. If you have ever opened a music player and felt tired just looking at it, Plinth is the opposite of that feeling.

Everything is arranged with Columns UI and JSplitter, which are well-known building blocks in the foobar2000 world. The Library, Playlist, Lyrics and About screens are set up as drawers, meaning they slide into view when you call them and slide away again so the artwork can breathe.

✨ What You Get

  • Album art first. A large, clean artwork area anchors the whole layout, so the record you are playing is always visible and always the focus.
  • Soft-grey, low-glare palette. A gentle grey scheme that sits comfortably next to a monitor for hours without harsh contrast or visual noise.
  • Library drawer. Browse your collection in a panel that tucks away neatly when you are done looking for something.
  • Playlist drawer. See the current queue and reorder tracks without permanently sacrificing screen space to a long list.
  • Lyrics drawer. Pull up the words to the song that is playing, then close it again to return to the artwork.
  • About drawer. A tidy place for theme credits and information, kept out of the way of your music.
  • Minimalist by design. No decorative clutter, no unnecessary labels, no oversized icons.
  • Built for Windows. Plinth is designed and tested around the Windows version of foobar2000.

📋 What You Need Before You Start

You do not need to know how to write code to use Plinth. You only need a few things already sitting on your computer:

  • A Windows PC running Windows 10 or Windows 11.
  • foobar2000 already installed. If you do not have it yet, install it first and make sure it opens normally.
  • The Columns UI component for foobar2000, which provides the layout system Plinth uses.
  • The JSplitter component, which handles the panels and drawers inside the layout.
  • The Spider Monkey Panel component, which powers the scripted panels that sit inside Plinth.

These components are free foobar2000 add-ons. They are installed the same way as any other foobar2000 component, and once they are in place the theme can be applied on top of them.

🛠️ Installing the Theme, Step by Step

Install the components first, then add the theme. Taking it in that order avoids confusion later.

  1. Close foobar2000. Make sure the player is fully closed before you change anything.
  2. Install Columns UI. Place the Columns UI component file into your foobar2000 components folder, then start foobar2000 again and follow the on-screen prompt if one appears.
  3. Install JSplitter. Do the same with the JSplitter component, again placing it in the components folder and restarting foobar2000.
  4. Install Spider Monkey Panel. Add the Spider Monkey Panel component the same way, then restart foobar2000 once more.
  5. Open the downloaded theme package. The package contains the layout files and any supporting pieces that came with Plinth. Keep the folder structure exactly as it is.
  6. Import the Plinth layout. In foobar2000, switch to Columns UI as your layout engine, then use the layout import option to load the Plinth configuration file from the package you downloaded.
  7. Restart foobar2000. After the import, close and reopen the player. You should now see the soft-grey Plinth window with album art in the centre.

If the layout does not appear straight away, check that Columns UI is the active layout and that all three components are listed as installed in foobar2000's component list.

🚀 Getting Started with the Drawers

Once Plinth is running, the window shows album art and basic playback controls. The four drawers are the Library, Playlist, Lyrics and About panels. They are not permanently visible, which is the whole point of the design.

Each drawer has a small tab or handle near the edge of the layout. Click or hover the tab and the panel slides open. Click it again and the panel slides closed. The drawers are arranged so they do not overlap the album art while they are shut, and the rest of the interface stays exactly where it was.

Use the Library drawer to find albums and artists, the Playlist drawer to manage what is playing next, the Lyrics drawer when you want to follow along with a song, and the About drawer when you want to check what version of the theme you are on. Because the panels are part of the JSplitter layout, they remember their position and size between sessions.

🖱️ Using Plinth Day to Day

Playback works the way it always does in foobar2000. The visual changes are what make Plinth feel different:

  • Drag a track into the player and the artwork appears in the centre of the layout.
  • Use the standard foobar2000 playback keys or on-screen controls to play, pause, skip and seek.
  • Click the Library tab to search your collection without leaving the main window.
  • Click the Playlist tab to see the order of upcoming tracks.
  • Click the Lyrics tab to read the words of the current song. Close the tab when you are done.

The layout is designed to be left alone. You do not need to rearrange panels or drag boundaries to enjoy it. The drawers are already in sensible places, and the album art area is already the right size. Plinth works best when you let it settle into that quiet default.

⚙️ Making It Yours

Plinth arrives quiet and grey, but you can adjust it without rebuilding anything. The most common changes are small and personal:

  • Change the shade of grey in the Columns UI colour settings if you prefer a slightly warmer or cooler tone.
  • Resize the album art area by dragging the split in the layout. JSplitter will remember where you left it.
  • Move the drawers to the left or right edge if that suits your monitor better.
  • Choose which panels appear in each drawer by opening the JSplitter settings and selecting a different panel from the list.

Keep the overall idea intact, though: the artwork should stay in the middle, and the drawers should stay out of the way until you need them. That is what makes Plinth feel calm rather than crowded.

❓ Troubleshooting Common Problems

The theme does not appear after importing. Check that Columns UI is selected as the layout engine in foobar2000 preferences. If the player is still using the default layout, the Plinth import will not show up.

The drawers are missing. This usually means JSplitter is not installed or is not the right version. Reinstall the JSplitter component from the same place you got the theme, then restart foobar2000.

The album art area is blank. Make sure the track you are playing has embedded artwork or a cover image in the same folder. Plinth uses the artwork that foobar2000 can already see.

A panel shows an error instead of content. Spider Monkey Panel may be missing or out of date. Install the Spider Monkey Panel component, then reopen foobar2000 so the scripted panel can load.

The layout looks cramped on a small screen. Drag the JSplitter boundaries to shrink the album art area slightly, or close one or two drawers. Plinth is responsive, but a very small window will always feel tight with four drawers in it.

📝 Notes on the Design

Plinth is part of a small family of foobar2000 themes that treat the player as a quiet frame for album art rather than a dashboard of controls. The soft-grey palette is intentional. It reduces glare, keeps text legible, and prevents the interface from fighting the colours in your cover images.

The name Plinth refers to the base that holds something up. In this theme, the plinth is the grey structure of panels and drawers, and the artwork is the object being displayed. That is why the drawers are designed to disappear when they are not needed: the base should support the art, not compete with it.

The theme is built for foobar2000 on Windows and uses Columns UI, JSplitter and Spider Monkey Panel. Those components are free and widely used, and they keep the layout flexible without requiring you to edit any code. Everything you need to get started is on the download page linked above.
